# 예스통신 액정 검수

중고폰(아이폰·갤럭시 공용) 매입 검수용 단색 화면 페이지입니다.
카운터에 붙은 QR코드를 손님 폰 카메라로 찍으면 바로 열립니다.
외부 라이브러리 없이 `index.html` + `manifest.webmanifest` 두 파일로 동작합니다.

## 검수 순서

| 순서 | 화면 | 확인 항목 |
|---|---|---|
| 1 | 순백색 흰색 `#FFFFFF` | 가장 밝은 화면 · 잔상·황변 (화면 밝기 최대로) |
| 2 | 10% 회색 `#1A1A1A` | 약한 OLED 번인·잔상 |
| 3 | 파란색 `#0000FF` | 블루 소자 잔상 |
| 4 | 빨간색 `#FF0000` | 적색 얼룩 |
| 5 | 초록색 `#00FF00` | 녹색 얼룩 |
| 6 | 50% 회색 `#808080` | 중간 밝기 얼룩 |
| 7 | 검정색 `#000000` | 휘점·빛샘 |
| 8 | 터치 테스트 | 화면 전체 격자 터치 |

## 조작

- **첫 화면에서 화면을 한 번 탭**하면 순백색 그대로 전체화면으로 들어갑니다. (색은 넘어가지 않습니다.)
  브라우저가 페이지 로드 직후의 자동 전체화면을 막기 때문에, 첫 탭을 전체화면 진입에 씁니다.
- **두 번째 탭부터** 다음 항목으로 넘어갑니다.
- **길게 누르기**(0.5초) 또는 우측 상단 **메뉴** 버튼 → 항목 선택 바
- **전체화면**: 첫 탭에서 진입하고, 항목 선택 바의 **전체화면 / 전체화면 해제** 버튼으로 직접 토글할 수 있습니다.
  `requestFullscreen`이 없는 브라우저(구형 아이폰 사파리 등)나 진입이 거절된 경우에는 첫 탭이 바로 다음 화면으로 넘어갑니다.
  (홈 화면에 추가해 실행하면 매니페스트의 `display: fullscreen`으로 처음부터 전체화면입니다.)
- 안내 문구는 2초 뒤 자동으로 사라지고, 그때 우측 상단 **메뉴** 버튼도 더 옅어져(불투명도 0.22) 잔상·가장자리 확인을 가리지 않습니다.
- 터치 테스트: 손가락으로 화면을 문지르면 지나간 칸이 초록색으로 채워지고 선이 그려집니다.
  격자를 끝까지 채우면 "전체 N칸 터치 완료"가 표시됩니다. **초기화** 버튼으로 다시 시작합니다.

## 삼성 인터넷 다크 모드(화면이 어둡게 반전될 때)

이 페이지는 `<meta name="color-scheme" content="light only">` 와 CSS `color-scheme: light only` 로
브라우저의 자동 다크 반전을 막습니다(안드로이드 크롬, 최신 삼성 인터넷은 이 신호를 따릅니다).

그래서 검수 색은 CSS 배경색이 아니라 `#colorCanvas` 캔버스에 직접 칠합니다(첫 화면 `#FFFFFF`).
화면 크기·회전·전체화면 전환 때마다 뷰포트 크기(`window.innerWidth/Height`, `devicePixelRatio`)에 맞춰 다시 채웁니다.
터치 테스트 모드에서는 캔버스를 숨기고 `#touchLayer` 격자가 그 위를 덮습니다.

그래도 삼성 인터넷에서 **순백색이 회색으로 보이면** 브라우저의 강제 다크가 켜진 것입니다.
이 기능은 페이지가 끌 수 없는 경우가 있어, 메뉴(항목 선택 바)에 설정 경로를 함께 표시합니다.

- 삼성 인터넷: **설정 → 웹페이지 보기 및 스크롤 방식 → 어두운 화면 모드 → ‘웹 콘텐츠에 어두운 화면 모드 강제 적용’ 끄기**
- 또는 **크롬**으로 열기
