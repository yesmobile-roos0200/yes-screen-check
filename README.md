# 예스통신 액정 검수

중고폰(아이폰·갤럭시 공용) 매입 검수용 단색 화면 페이지입니다.
카운터에 붙은 QR코드를 손님 폰 카메라로 찍으면 바로 열립니다.
외부 라이브러리 없이 `index.html` + `manifest.webmanifest` 두 파일로 동작합니다.

## 검수 순서

| 순서 | 화면 | 확인 항목 |
|---|---|---|
| 1 | 순백색 흰색 `#FFFFFF` | 가장 밝은 화면 · 잔상·황변 (화면 밝기 최대로) |
| 2 | 10% 회색 `#1A1A1A` | 약한 OLED 번인·잔상 |
| 3 | 파란색 `#0000FF` | 블루 소자 잔상 |
| 4 | 빨간색 `#FF0000` | 적색 얼룩 |
| 5 | 초록색 `#00FF00` | 녹색 얼룩 |
| 6 | 50% 회색 `#808080` | 중간 밝기 얼룩 |
| 7 | 검정색 `#000000` | 휘점·빛샘 |
| 8 | 터치 테스트 | 화면 전체 격자 터치 |

## 조작

- 화면 아무 곳이나 **탭** → 다음 항목
- **길게 누르기**(0.5초) 또는 우측 상단 **메뉴** 버튼 → 항목 선택 바
- **전체화면**: 첫 터치부터 자동 진입을 시도하고, 전체화면을 나간 뒤 화면을 다시 만지면 재진입합니다.
  항목 선택 바의 **전체화면 / 전체화면 해제** 버튼으로 직접 토글할 수도 있습니다.
  (터치 테스트 중에는 자동 진입을 하지 않습니다. 홈 화면에 추가하면 매니페스트의 `display: fullscreen`으로 열립니다.)
- 안내 문구는 2초 뒤 자동으로 사라지고, 그때 우측 상단 **메뉴** 버튼도 더 옅어져(불투명도 0.22) 잔상·가장자리 확인을 가리지 않습니다.
- 터치 테스트: 손가락으로 화면을 문지르면 지나간 칸이 초록색으로 채워지고 선이 그려집니다.
  격자를 끝까지 채우면 "전체 N칸 터치 완료"가 표시됩니다. **초기화** 버튼으로 다시 시작합니다.
